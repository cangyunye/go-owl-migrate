# 任务管理

## 任务状态

| 状态 | 含义 |
|---|---|
| running | 正在执行 |
| completed | 全部成功完成 |
| failed | 执行出错 |
| cancelling | 已发送取消信号，等待 Worker 退出 |
| cancelled | 已取消 |
| interrupted | 异常中断（崩溃、服务重启） |

## 任务历史

「任务」页列出所有任务，按创建时间倒序。点击任务 ID 查看详情：

- **检查点**：每张表的导出/导入状态与行数
- **事件流**：完整的进度事件记录

## 服务重启后的恢复

服务启动时，所有 `running` 状态的任务会被自动标记为 `interrupted`。
这些任务的检查点与事件记录都会保留，可以查看或恢复。

## 恢复任务

对 `interrupted` 或 `cancelled` 的任务，点击「恢复」：

- 系统新建一个任务，携带「基于检查点续跑」标识
- 已成功的表直接跳过
- 旧任务的全部进度事件保留，可供查阅

## 数据存储

任务状态、检查点、进度事件均存储在 SQLite 文件
（默认 `<temp-dir>/owl-migrate.db`），服务重启不丢失。
