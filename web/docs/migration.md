# 完整迁移流程

## 两种模式

| 模式 | 说明 | 是否需要目标库 |
|---|---|---|
| 直接迁移 | 源库导出 → 目标库导入 | 需要 |
| SQL 输出 | 源库导出 → 生成 INSERT SQL | 不需要 |

## 执行步骤

迁移任务在独立 Worker 子进程中运行，依次执行：

1. **加载元数据**：从 CSV / XLSX / 源库读取表结构
2. **连接源库**：验证连通性
3. **连接目标库**（直接模式）
4. **创建目标表**（直接模式，可跳过）
5. **导出数据**：按主键游标分页并行导出为 CSV
6. **导入数据**（直接模式）或 **生成 INSERT SQL**（SQL 模式）
7. **生成报告**

## 实时进度

页面通过 WebSocket 接收每张表的进度事件：

```
[1] export_complete SCOTT.EMP → 14000 rows
[2] import_complete SCOTT.EMP → 13998 rows
```

刷新页面或断开重连后，会自动重放该任务的全部历史事件。

## 断点续传

任务中断（崩溃、取消）后，已完成的表会记录检查点。
在任务详情页点击「恢复」，新任务将跳过已完成的表，只处理剩余部分。

## 取消任务

点击「取消」按钮，服务向 Worker 发送信号。Worker 会完成**当前表**的
当前批次后退出，不会在行中间中断，避免产生部分写入的数据。
